# 共有定義による作曲準備の試作

パターンの式を一か所で編集し、参照するセクションへ反映するための開発用試作です。`examples/light-orbit/named.json` はパターン、参照の組合せ、曲順を分けます。小節・拍は配置の表記であり、フレーズ周期を小節の倍数に制限しません。

## 検証

MoonBitと依存パッケージを導入し、`npm run verify:composition-authoring` を実行します。既存構文の「光の軌道」と全曲イベントが一致すること、定義の変更・配置・長さ・ランダムな音抜きに対して差分準備が全体再準備と一致すること、最新編集と取消しの競合を検証します。結果は `artifacts/composition-prototype/definition-check.json` です。

## 境界

`named.mjs` は名前を既存構文へ展開します。式をJavaScriptとしてevalしません。`prepare.mjs` は明示的に渡されたコンパイラを使い、有限イベント列と次のキャッシュを返します。`worker.mjs` がコンパイラとキャッシュの寿命を所有し、`preparation-queue.mjs` は実行中1件と最新待機1件に制限します。取消しは結果を無効にしますが、実行中のコンパイル自体を中断しません。

120 BPM、4/4、48kHz、128フレーム、最大256拍に限定します。定義と問い合わせ範囲が同じ場合だけ結果を再利用します。全曲イベント列の再構築と転送は毎回必要です。`prepare` は全体再準備の比較基準、`prepareIncremental` はScene単位の比較基準、`prepareDefinitions` がWorkerで使用する方式です。

この段階では再生画面、ライブ更新、エフェクトは含みません。JSONは意味を検証する試作形式であり、既存言語の公開構文を変更しません。
