Help & sounds

moondsp is a score you can read, draw, and hear. Every phrase is code; the grid under your cursor edits that same code, even while it plays. Press Play, change a note, and listen. Undo always brings it back.

Draw a melody

Place the code cursor in a note("…") phrase. Its note grid opens directly beneath the code. Rows are pitches; time runs left to right. Click a block to select its source note. Click or tap an empty source-rest interval to place a note at that pitch. Releasing the pointer commits; Escape cancels the preview and Undo restores the phrase.

Drag a note up/down to change pitch and sideways to reorder it within its written sequence. Occupied steps shift rather than being overwritten; the moved note keeps its weight and repetitions. Horizontal movement follows source steps, not arbitrary time positions. Drag a note's left or right edge to trade time with its adjacent source step while keeping the other boundaries fixed. A dashed preview shows the result before release.

To edit several notes together, turn on Select and drag from the first source step to the last, or use Left/Right to extend or shrink the selection. Select again or Escape leaves selection mode. Drag a selected note to move the whole range; Up/Down transposes it and Alt+Left/Right moves it one sibling step. The same complete source range can be selected in code. Duplicate inserts an independent copy after the range, adding steps within the notation's existing cycle; Repeat keeps occurrences linked. Neither operation overwrites other notes. Ranges stay within one written sequence.

Shift-drag a note, or start drawing in empty grid space, to change a contour across existing notes in one edit without filling crossed rests. Open Structure for source steps and nested groups. Split divides one written step into two; Repeat edits its *n suffix. Repeated appearances stay linked to the same source step. Drag a source-strip boundary, or adjust Share, to trade time with the next sibling. Rest writes ~ without removing suffixes. On a selected rest, Add note or Add chord uses a neighboring value, or C4/C when the phrase is entirely rests.

Use Play to hear your score, including its tempo, effects, and other parts. Editing never starts a separate preview. You can keep editing during playback; changes take effect at each part's next entry. Near an edited phrase, Queued and Sending mean the edit is not accepted yet. Accepted · score still updating reports score-wide pending material, not proof that this phrase is already sounding. The notice clears when the current score has no pending changes. Ctrl/⌘+Enter toggles Play/Pause from the code or drawing.

Tab focuses the grid. Left/Right selects a source step; Up/Down changes a note by one semitone. Alt+Left/Right moves the selected note one source step; Shift+Left/Right resizes its right boundary. Delete/Backspace clears it to a rest. Enter starts a drawing, arrows move its preview, and Enter commits. For a selected rest, Enter starts note entry, Up/Down chooses the pitch, and Enter commits. Escape cancels unfinished edits and returns to code. Ctrl/⌘+Z and Ctrl/⌘+Shift+Z share Undo and Redo.

Edit chords

Place the cursor in chord("C Am F G7") and select a numbered chord. Drag one of its tone blocks up or down to change that note. Drag Move chord to transpose all its notes together. Tap an empty pitch row or use Add tone to add a note; select a block and use Remove tone to remove it. Lower/Raise changes the selected tone, or the whole chord when Move chord is selected. The outlined source step is the one you are editing; filled steps and tones follow actual playback.

Drag previews do not change the score until release. Escape cancels; each completed change shares Undo and the main Play transport. In the tone grid, Left/Right selects a tone, Up/Down changes its pitch, Shift+Up/Down moves an octave, and Delete removes it. Move chord also accepts Up/Down. Add tone supports keyboard entry into a rest. Notes already present and pitches outside MIDI 0–127 are rejected, not silently merged.

The source uses a chord name when it describes the exact notes; other voicings and inversions use explicit pitches such as chord("{64,67,72}"). Removing every tone writes ~. Weights, repetitions, and surrounding code stay intact. Choose by chord name offers optional Root/Type choices for named chords; these are unavailable for custom sets. View chord tones opens a separate inspection of the whole progression: its blocks select whole chords, not individual notes. Repeated occurrences stay linked to the same written chord. Slash-bass names are not supported; edit the tones directly instead.

Percussion steps

In s("…"), rows choose Kick, Snare, Hi-hat, Open hat, or Clap. Tap an empty cell to set that sound; tap a filled cell to clear it to ~. Choosing another row replaces that step's sound. Click a column number to select without editing. Arrow keys move between cells; Space/Enter edits, and Escape returns to code.

Each column is one written source step, not an equal slice of playback time. Weights, nested groups, and repeated occurrences stay linked to the source; open Structure for group and boundary edits. The matrix scrolls horizontally on narrow screens. Simultaneous layers remain in code. These are the existing built-in percussion sounds, not sample-file import.

From a step to a pattern

s("bd ~ sd ~") plays a kick, a rest, a snare, then a rest. The spaces divide the pattern into equal steps.

note("C4 E4 G4 ~") does the same with pitches. Numbered steps select without changing the score or starting playback. Choose a key to change the selected note. Rest clears it; Add note fills a selected rest. Undo restores the previous value.

Pitch controls contains the chromatic keyboard and octave browsing. The keyboard runs from low to high; Octave −/+ browses without editing. Its open state follows the phrase for this session.

Left/Right moves between numbered steps or pitch keys; Space/Enter selects. On a numbered note step, Up/Down changes pitch by one semitone; Shift moves an octave. Escape returns to your code selection. The toolbar's Undo/Redo and their Ctrl/⌘+Z shortcuts act on both text and graphical edits.

bpm(96); sets the tempo. .slow(2) stretches a pattern to twice its length.

What the controls can edit

The drawing follows the notation inside quotes, including subdivisions, repetitions, parallel layers, chords, and rests. Its source strip selects the written step or group; an edit changes every linked occurrence, never just one repeated copy. Outer transformations, arrangements, and effects remain code and are not folded into this local drawing. Complex or oversized notation stays editable in code when a safe graphical edit is unavailable.

A block's left edge shows its start and its width shows its interval in the quoted notation, not the synth's gate or release. The ruler measures local cycles, before outer speed and song placement—not bars. Choose 4 divisions for quarter-cycle guides; labels such as 2.3 mean the third division of local cycle two, not a claimed time signature. Dashed edit previews include displaced neighboring notes. Chords appear as separate pitch blocks. Explicit note rests remain blank but accept note entry; silence from other notation operations is not an insertion target. Overlapping rest sources require selection in Structure rather than a guessed edit. The outline marks your selection; a solid fill marks the latest played notes.

Timing separates three operations. Weight changes a step's relative @1–@16 share and may move following onsets. Phrase stretch edits or adds .slow(n), including fractions. Phrase gate edits or adds .gate(n), changing sounding duration without moving onsets; explicit envelopes may determine the audible release instead. Existing transformations and formatting are preserved. Each committed edit is one Undo step.

The small knobs edit gain and filter values for note and chord voices. Browser drums are not affected by those modifiers. Drag vertically, use arrow keys, or press Enter to type a number.

Controls hides or shows both the drawing and sound controls without changing your music.

Files & recovery

Import opens a plain-text score; Download saves a .mini file you can edit, share, or use with your own AI tools. Nothing is sent to an AI service.

Share copies a link that opens this score. The score travels inside the link itself; nothing is uploaded. Opening a link replaces your text once, and Undo restores it.

Each edited session saves a separate recovery copy before updating the shared saved score. Saved drafts contains recovery copies from other sessions. Restore supports Undo. If tabs save at the same time, both drafts remain available after reopening, even if one replaces the shared score. You can permanently delete a saved draft after confirmation. Copies stay in this browser until you delete them; Download keeps a separate file. If browser storage is full or unavailable, download your open score before leaving.

Playback & updates

Play starts or resumes the accepted score; Pause freezes it. Restart applies the editor's score from the beginning. Use Ctrl/⌘+Enter for Play/Pause and Ctrl/⌘+Shift+Enter for Restart.

Updates take effect at each material's next entry. Pending changes wait while the current phrase finishes. Invalid code leaves Current song unchanged. Author tempo with bpm(90);; omitted tempo is 60 BPM.

Triggered notes, their source, and named references stay highlighted until the next note starts. Simultaneous notes light together; rests keep the previous highlight. Pause clears it. This shows the latest note starts, not note duration or proof that every edit has taken effect. After a notation edit, unchanged code atoms may stay highlighted even when the drawing cannot identify the older events.

Playback details counts cycles, not bars or seconds. Parts can have different cycle lengths. Accepted edits switch at each part's entry, not all at once.
