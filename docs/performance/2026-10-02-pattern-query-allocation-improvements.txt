Implemented, public signatures unchanged
- PatternNodePath uses immutable shared tails instead of copied descendant
  arrays. Prepend constructs a shared link without nodes()/array-copy chains.
  nodes() still returns a fresh independently mutable root-to-leaf array with
  duplicates preserved; exact-size allocation avoids array growth. Public
  equality and Debug field shape are preserved. Runtime/Atom lowering prepares
  invariant leaf paths outside per-event map callbacks.
- Rational add/subtract-zero and multiply/divide-by-positive-one return existing
  immutable normalized operands. Division by zero remains an error. General
  cancellation/overflow-safe arithmetic and exact Int64 fractions are unchanged.
- TimeSpan/Event zero shifts return the immutable input. Nonempty contained
  intersections reuse an existing span; empty/touching intervals remain None.
- Retained varying-depth path, varying-operand time, and isolated sourced-query
  benchmarks, plus behavioral tests for path ownership/branch isolation and
  numeric/span/event boundaries. No pool, runtime cache, float conversion or
  mutable shared result array was introduced.

Scope and remaining work
This completed batch reduces allocation; it does NOT meet the no-audio-thread-
allocation goal. Dense render still executes3,619,295 GC constructors per600
blocks. Remaining event/scoped-value arrays and non-identity rational/time
construction require further isolated measurement and a render-safe output/work
buffer design. No claim is made that every remaining constructor is necessary.
GC instruction counts do not map one-for-one to V8 trace records. Native/runtime
coverage, physical backing storage, callback-duration percentiles, GC pauses and
actual deadline/underrun compliance remain unproven. Frame step128 alone proves
none of those. No native/CLAP/graph/browser ABI/sourceMap policy changes were made.
