Retained implementation
- sequence computes its scale, indices and rational slot bounds at construction.
  One private immutable SequenceSlot record per child replaces repeated
  per-query computation. The caller's pattern array remains copied as before.
- Every complete slot maps to [0,1) in child-pattern time. One immutable span
  is prepared at construction and reused. Requested event parts still clip
  against the independently computed query span.
- whole_cycles advances to cycle_end instead of computing cycle_start + one
  a second time. Int64 arithmetic and half-open boundaries remain exact.
- No generic constructor branches, float replacement, mutable interning table,
  output pool, query-result cache, or public compatibility layer remains.
